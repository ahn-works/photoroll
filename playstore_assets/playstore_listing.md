## 2. 자세한 설명 (Full Description - 최대 4,000자)

```markdown
잠금화면에만 가능했던 사진 여러 장 자동 변경, 이제 갤럭시 홈 화면에서도 마음껏 누리세요!

‘PhotoRoll Galaxy’는 내가 사랑하는 반려동물, 소중한 가족, 여행지 풍경, 최애 아이돌 사진을 갤러리에서 골라 홈 화면과 잠금화면에 내가 원하는 조건대로 자동 교체해 주는 프리미엄 다이내믹 배경화면 앱입니다.

갤럭시 기본 잠금화면 멀티팩의 한계를 넘어, 홈 화면과 잠금화면을 자유롭게 컨트롤해 보세요.


✨ PhotoRoll만의 차별화된 핵심 기능

1️⃣ [화면 켤 때마다 즉시 변경]
스마트폰 화면을 켜거나 잠금을 해제할 때마다 새로운 사진이 홈 화면 전체에 부드럽게 펼쳐집니다. 

2️⃣ [내 라이프스타일에 맞춘 다양한 교체 조건]
- 화면 켤 때마다 (Screen On)
- 주기적 변경 (15분 / 30분 / 1시간 / 3시간 / 6시간 등)
- 매일 지정된 시각 (출근길 08:00, 점심 12:00, 취침 전 등)
- 주말/평일 분리 모드: 평일엔 차분한 풍경 앨범, 주말엔 활기찬 취미 앨범으로 자동 스위칭!
- 홈 화면 빈 공간 더블 탭: 두 번 톡톡 터치하면 즉시 다음 사진으로 스킵

3️⃣ [스마트 사진 순환 & 추천 알고리즘]
- 비복원 랜덤 셔플: 전체 사진이 한 번씩 다 나올 때까지 중복 없이 고르게 순환
- 순서대로 재생: 내가 정렬한 순서 그대로 재생
- 즐겨찾기 가중치 셔플: 하트(❤️) 누른 최애 사진이 3배 더 자주 등장
- 주야간 감성 매칭: 낮에는 화사한 사진, 밤에는 눈부심 없는 감성 다크 사진 자동 배정

4️⃣ [홈 화면 & 잠금화면 독립 제어]
잠금화면은 켤 때마다 랜덤하게, 홈 화면은 1시간마다 차분하게! 각각 다른 앨범과 주기로 똑똑하게 분리 설정할 수 있습니다.

5️⃣ [홈 아이콘 가독성 보호]
사진이 너무 밝아 앱 아이콘과 시계가 안 보일까 봐 걱정되시나요?
0% ~ 50% 가독성 딤(Dim) 슬라이더를 지원하여 선명한 앱 아이콘 가독성을 보장합니다.

6️⃣ [배터리 누수 0% 설계]
정지 이미지 기반의 온디맨드 캔버스 렌더링 기술로, 화면이 꺼져 있거나 다른 앱을 사용할 때는 CPU 점유율이 0%로 완벽 차단되어 배터리 소모가 일반 배경화면과 동일합니다.

7️⃣ [핀터레스트 1초 연동 지원]
핀터레스트에서 마음에 드는 핀을 발견하셨나요? [공유] → [PhotoRoll]만 누르면 즉시 내 배경화면 덱에 고화질 원본이 자동 등록됩니다.

8️⃣ [갤럭시 One UI 빠른 설정 타일 지원]
앱을 직접 열 필요도 없습니다! 화면 상단바를 아래로 쓸어내려 'PhotoRoll' 타일을 한 번만 탭하면 즉시 다음 사진으로 넘어갑니다.


🔒 완벽한 개인정보 보호 (100% On-Device)
PhotoRoll은 사용자의 사진이나 개인정보를 외부 서버로 절대 전송하지 않습니다. 모든 작업은 고객님의 스마트폰 안에서만 안전하게 실행됩니다.


지금 바로 다운로드하고, 매일 폰을 켤 때마다 나만의 소중한 추억들로 기분 좋은 설렘을 느껴보세요!
```
